## 做了什么

7 个提交，净改动 13 个文件、528 行。Dart 客户端代码（聊天、远程配对/中继/LAN/SSH、l10n、主题）原样复用，新代码集中在三块：

1. **平台判定与入口隐藏**（`lib/state/platform_state.dart`、`settings_screen.dart`）：新增可注入的 `isIosProvider`；iOS 上不渲染手机操控瓦片、本机引擎瓦片、概览卡引擎 footer。引擎参数瓦片和远程主机瓦片**保留**（对远程主机生效，见决策 5）。
2. **引擎启动门禁**（`engine_control.dart`、`root_gate.dart`）：`EngineControl.ensureStarted`（所有手动启动路径的汇聚点）和 `_maybeAutoStart`（冷启动自动启动，直调 `.start()` 绕开前者）在 iOS 上直接返回。
3. **Swift 原生桥**（`ios/Runner/DshGoChannels.swift`，247 行）：实现 `dsh/app`（bringToFront/时区）、`dsh/notify`（`UNUserNotificationCenter` 本地通知 + taps 事件流，载荷写进通知 `userInfo`）、`dsh/links`/`dsh/share`（ready 应答 + native→Dart 推送骨架）、`dsh/files.open`、`dsh/diagnostics`；另用通用桩吞掉 27 个 Android 专属通道（`dsh/runtime*`、`dsh/phone*`、`dsh/launcher_icon`、`dsh/islands`、`dsh/launch*` 等），方法调用一律 `notImplemented`、事件流为空，Dart 侧既有的 try/catch 自然降级。深链走 SceneDelegate（scene 生命周期下 AppDelegate 的 `application(_:open:)` 不触发）。`Info.plist`：显示名 AgentPort，bundle id `com.xcoder.agentport.ios`。
4. **web 模式聊天**（`pubspec.yaml`）：加 `webview_flutter_wkwebview ^3.27.2`，把电脑上的 DSH Web 加载进全屏 WKWebView。

新写 3 个 Dart 测试（`test/ios_feature_visibility_test.dart`、`ios_boot_degrade_test.dart`、`ios_notify_contract_test.dart`），全过。

## 重要决策与理由

### 立项前（已写入设计文档）

- **iOS 只做远程客户端，不跑本地引擎**——iOS 系统不允许 App 内运行 Linux 环境，PRoot 不可移植（用户明确拍板）。
- **v1 不做后台保活**——远程任务完成推送要么走服务器 APNs（中继服务器没有此能力，属另一个项目），要么走 VoIP 后台模式（苹果对非通话应用收紧审核）；dart:io WSS socket 挂起即断。v1 采用"前台为主 + 前台自动重连"：`dsh_remote` 传输层自带 backoff 重连，解锁回前台立即同步任务状态。后台推送记为未来事项。
- **保留 SSH 远程通道**——`dartssh2` 是纯 Dart，iOS 可用；砍掉反而要动 pubspec 和删 `HostKind.ssh` 处理。
- **保留 web 模式聊天**——把电脑上的 DSH Web 加载进全屏 WKWebView，`webview_flutter_wkwebview` 现成，体验与安卓版一致。

### 执行过程中（裁决记录）

1. **Dart 包名保留 `dsh_app` 不重命名**——`package:dsh_app` 有 1025 处 import；设备可见的品牌（应用名、bundle id）已是 AgentPort，包名是内部标识，重命名无用户收益，纯机械成本。
2. **新仓库不拷 `runtime/`、`sdk/`、`tooling/`**——iOS 版用不到引擎补丁、插件 SDK、APK 构建脚本。
3. **Swift 通道全部放进现有 `DshGoChannels.swift` 一个文件**——旧式 pbxproj 每加一个源文件要改 4 处 UUID，手改风险高；单文件零构建破坏风险。
4. **通用桩吞掉 27 个 Android 专属通道**——逐通道写 Swift 是用不上也测不了的徒劳；桩返回安全默认值，Dart 侧既有容错自然降级。`dsh/web-files` 归桩（Dart 侧 `platform is! AndroidWebViewController` 拦住，WKWebView 自管）。
5. **引擎参数瓦片和远程主机瓦片不藏**——"引擎参数"显示的是**当前主机**的引擎参数（远程主机也生效）；只藏"本机引擎"瓦片、手机操控瓦片、概览卡引擎 footer。评审曾漏了概览卡 footer（仍指向本地引擎页），已修。
6. **重连和信任恢复不重复写测试**——`dsh_remote` 传输层自带 backoff，App 侧已有 `session_titles_reconnect_test`；`HOST_NOT_TRUSTED` 的信任对话框和"重新信任"恢复路径已实现且有测试。
7. **tap 载荷写进通知 `userInfo` 而不是内存 map**（评审 Important #3）——内存 map 在 iOS 杀掉进程后丢失，点旧通知取不到 sessionId 会被 `NotifyTap.fromMap` 静默丢弃；`UNNotificationRequest` 冷启动后还在。
8. **`dsh/notify` 的 cancel/cancelGroup 必须回 `result(nil)`**（评审 Important #2）——平台通道调用不回 result，Dart 侧 Future 永不完成；现在被 `unawaited` 掩盖，未来的 `await` 会挂死。
9. **webview 包名是 `webview_flutter_wkwebview ^3.27.2`**——不是 `webview_flutter_ios`（不存在）；接口包 2.x 对应的 iOS 实现是 3.x 系列（源仓库 `pubspec.lock` 佐证）。
10. **`dsh/app` 的 `setRefreshRateMode` 和 `initializePairingScanner` 返回空成功**——CADisplayLink 降频超出"少量 Swift"预算；ML Kit 配对扫描是 Android 专属。配对用摄像头扫码的替代路径（中继 URL/手动输入）在 Dart 层已有。

### 未修的 Minor（记账）

- `dsh/links` 的 `ready: true` 但 Info.plist 没注册 URL scheme（`CFBundleURLTypes`），深链实际不会送达——加 scheme 是配置项，不阻塞远程客户端核心用法。
- `dsh/files.open` 是空实现——远程主机产物文件的"打开"按钮不弹系统分享。
